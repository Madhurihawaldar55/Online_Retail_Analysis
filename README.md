# **Online_Retail_Analysis**
### Project Overview

This project presents an interactive sales analysis dashboard built using Tableau.
It provides insights into sales trends, customer behavior, and country-wise performance for an online retail dataset.
### Objectives
- Analyze monthly sales trends
- Identify top-performing countries
- Understand customer contribution to revenue
- Discover business growth opportunities
### Dashboard Features
- Monthly Sales Trend Analysis
- Country-wise Revenue & Quantity
- Global Sales Distribution Map
- Top Customers by Revenue
### Story Insights
- Sales increase significantly from September to November
- November records highest sales, followed by a drop in December
- Europe is the strongest market
- Few customers contribute a large portion of revenue
- Potential growth in underperforming regions
### Tools & Technologies
- Tableau – Data Visualization
- Excel / CSV Dataset – Data Source
